## Sprint 9 · Nov 16 – Nov 22, 2026

### What shipped

#### fieldwire_client_ucsh
39 done · 312 points · 41 pull requests merged (Xilous, roney4719) · 20 releases, v3.0.285 to v3.0.304

- **Jobs run as fast as Fieldwire allows.** Set up, update and mirrors now pace themselves from Fieldwire's own remaining-request counts instead of a cap of our own, batch a door's new checklist lines and run mirror streams side by side, while leaving room for people working in the app. A mirror of a 680-door project had taken about 2 h 40 min where about 1 h was possible. ([#1381](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1381))
- **Project settings covers the whole setup.** Settings is now a dashboard with the managers that existed only in Fieldwire's web app: project information, door fields, checklists, locations, report templates, and color and logo, with drag and drop to reorder. ([#531](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/531))
- **Switching region shows the right projects.** Switching between Ontario and BC now reads every project list again, so BC shows the BC account's projects instead of the list read at launch. ([#1406](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1406))
- **BC sums repeated hardware lines.** BC set up and update kept only the first of two identical lines on a door and lost the rest of the quantity; they now sum them as Ontario does, and the door's hardware table shows model and finish as their own columns. ([#1437](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1437))
- **The door page on one screen.** A door's details, plan, checklist, related tasks, photos and comments now sit on one page, as in Fieldwire web, with fields edited in place, the full checklist text and a mini map of the door's pin. ([#1486](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1486))
- **Sign-in with an emailed code, Clerk removed.** People sign in with their company email and a 6 digit code, and only a Fieldwire user in the Ontario or BC account gets in. Profiles live in our own users table, and roles are gone. ([#1530](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1530))
- **A rebuilt activity panel.** Activity is now a top bar button that opens almost full screen, showing each run's steps, time left and log. A waiting run says why, a quiet one warns it may be stuck, and you get a message when your run ends. ([#1610](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1610))
- **Changes follow each person's own Fieldwire role.** A follower can no longer make admin-level changes through the app, and nobody is made an admin by it. The older parent for ending the one shared Fieldwire session behind every sign-in also closed. ([#768](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/768), [#438](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/438))
- **Doors named by room.** The door finder moved to the new model workspace, and pin review names a door with no number after the room it opens into. Scoring on unseen architects carries on in [#1416](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1416). ([#1156](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1156))
- **Restart to update without the setup wizard.** Updates no longer run the old uninstaller, which froze the 3.0.265 install twice. The version shows in the account menu, and a developer can push a version to everyone. ([#1356](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1356))
- **UCA electrified openings from Titan.** UCA, the Ontario electrified division, now has its own Titan initialize project and update on Ontario projects, with an ADO task related to each opening that needs one. ([#1412](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1412))
- **UCA runs ask for their categories.** Every UCA run asks which category gets the electrified openings and which gets the ADO tasks, instead of finding them by a fixed name. ([#1513](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1513))
- **License notices in the installer.** The installer now carries the license notices of every open-source part it bundles, opened from the account menu, and the backend shrank from 150.6 MB to 138.2 MB. ([#1128](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1128))
- **Updates download only what changed.** An update replaces only the changed files, with the full installer as the fallback, instead of one 100 MB program for every backend change. ([#1464](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1464))
- **Door start and end dates.** Dates show and are edited on the door page, can be set in bulk for any selection, and are written the way Fieldwire's gantt and calendar expect. ([#1614](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1614))
- **Set up skips unused room fields.** Set up no longer writes three room fields nothing reads; on a 680-door project they were 26% of attribute writes, all on Fieldwire's most limited endpoint. ([#1109](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1109))
- **Mirror options switchable at any time.** Any option of a running mirror can be turned off, deleting nothing, or on, copying it in full, and mirrors now copy form templates. ([#1357](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1357))
- **A new mirror copies at once.** A new mirror copies everything as part of its build instead of waiting for the next hourly sync, and a retry can never make a second copy. ([#1405](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1405))
- **Automations use the official names.** The sidebar reads UCSH Automations: Initialize Project, Update Hardware Schedule, Task Pinning Tool and Set Task Location Tiers. Ontario also gets back BC's related tasks by opening step. ([#1418](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1418), [#1601](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1601))
- **Set up shows what it will add.** Ontario set up previews the doors and checklist items it will add before any write, which matters on a project that already has doors. ([#1461](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1461))
- **Releases on the app's own GitHub releases.** Each version is published on the repository's own releases instead of uploaded to the releases site, and waits for the server deploy of the same commit. ([#1570](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1570), [#1578](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1578))
- **Faster opening.** Plan pins arrive with the plan, and a relaunch reuses the copy on disk instead of reading every project again. ([#1364](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1364), [#1339](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1339))
- **Failed runs say why.** A run with nothing usable now stops with the reasons instead of going green and vanishing, and the two failed initialize project runs on South Niagara Hospital and CAMH Forensics Ph1D were traced and fixed. ([#1545](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1545), [#1555](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1555))
- **Door page and settings fixes.** List fields show their option's name instead of an id, empty fields show as the project's settings say, and each project uses its own Fieldwire time zone. ([#1477](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1477), [#1632](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1632), [#1637](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1637))
- **Small additions.** A check for updates button, a back-to-home button by the project name, and tagging every task related to a pasted list of doors. ([#1581](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1581), [#1419](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1419), [#655](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/655))
- **Earlier sign-in fixes.** New people could create an account, ucaccess.com staff can sign in, and anyone can pick Ontario or BC. ([#1290](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1290), [#1454](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1454), [#1525](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1525))
- **Upkeep.** CI dropped steps that did nothing, and an install cut off part way now fails the run. ([#961](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/961), [#962](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/962))
