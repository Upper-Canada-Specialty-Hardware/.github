#### fieldwire_client_ucsh
39 done · 312 points · 41 pull requests merged (Xilous, roney4719) · 20 releases, v3.0.285 to v3.0.304

- **Jobs run as fast as Fieldwire allows.** Jobs and mirrors now pace themselves from Fieldwire's own remaining-request counts instead of our own cap, batch a door's checklist lines and run mirror streams side by side. A 680-door mirror took about 2 h 40 min where about 1 h is possible. ([#1381](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1381))
- **Project settings covers the whole setup.** Settings is now a dashboard that adds what only Fieldwire's web app could do: door fields, checklists, locations, report templates, colour and logo, and project information, with drag and drop to reorder. ([#531](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/531))
- **The BC region shows BC projects.** Switching region now re-reads every project list for the new account. Anyone may pick Ontario or BC; the region is no longer a sign-in role. ([#1406](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1406), [#1525](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1525))
- **BC sums repeated hardware lines.** BC set up and update kept only the first of two identical lines on a door and lost the rest of the quantity. They now add them into one line, as Ontario does, and the hardware table splits model and finish. ([#1437](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1437))
- **The door page fits on one screen.** Details, plan, checklist, related tasks, photos and comments sit together in three zones, edited in place by double-click, with full checklist text, who created each line and a mini map of the door's pin. List fields show their choice by name, and every field the project shows appears, empty or not. ([#1486](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1486), [#1477](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1477), [#1632](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1632))
- **Sign-in with an emailed code.** People sign in with a company email and a 6-digit code from the access service, as long as they are a Fieldwire user in the Ontario or BC account. Clerk is gone. Earlier sign-in fixes closed with it, including ucaccess.com staff. ([#1530](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1530), [#1454](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1454), [#1290](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1290))
- **A usable activity panel.** Activity is a top-bar button opening a near-full panel of every run on the account, with steps, time left and the log. A waiting run says why, a quiet one warns it may be stuck, and you are told when your own run ends. ([#1610](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1610))
- **Changes follow each person's Fieldwire role.** The app no longer makes anyone an admin, and the UCSH API account joins a project only when Fieldwire refuses a write. This also closes the older shared-session issue. ([#768](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/768), [#438](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/438))
- **Pinning names doors after their rooms.** The door finder moved to the new model workspace, and a door with no number is named after the room it opens into. Scoring on unseen architects carries on in [#1416](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1416). ([#1156](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1156))
- **Updates without the old uninstaller.** Restart to update skips the setup wizard and the old uninstaller that froze installs, closing the app installs a waiting update, and the version shows in the account menu. ([#1356](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1356))
- **UCA runs on Titan.** The Ontario electrified division has its own copy of BC's Titan initialize project and update, picked by file type, with ADO tasks related to their openings. ([#1412](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1412))
- **UCA asks for its categories.** Every UCA run asks which category holds the electrified openings and which the ADO tasks, and division checks became warnings. ([#1513](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1513))
- **License notices in the installer.** The installer carries the license texts of its open-source parts, opened from the account menu, and the backend shrank from 150.6 MB to 138.2 MB. ([#1128](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1128))
- **Updates download only what changed.** An update replaces only the changed files, with the full installer as the fallback, and a check for updates button sits in the top bar. ([#1464](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1464), [#1581](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1581))
- **Releases live on GitHub.** Versions publish to the app's own GitHub releases, which the releases site redirects to, and a release waits for the server deploy of the same commit. The public releases repository, fieldwire_client_ucsh_releases, carried 35 releases, v3.0.270 to v3.0.304. ([#1570](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1570), [#1578](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1578))
- **Door start and end dates.** Dates show on the door page, are edited in place and can be set in bulk, in each project's own Fieldwire time zone, which project settings now shows. ([#1614](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1614), [#1637](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1637))
- **Fewer writes in set up.** Set up stops writing three unused room fields, which on one 680-door project were 26% of attribute writes. ([#1109](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1109))
- **Mirror options switch on a running mirror.** Every option can be turned on or off at any time. Off deletes nothing, on copies in full on the next pass, and form templates sync too. ([#1357](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1357))
- **New mirrors copy at once.** A new mirror copies itself right after setup instead of sitting empty until the next hourly slot, and a retry can no longer make a second copy. ([#1405](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1405))
- **Official names for the automations.** The sidebar reads UCSH Automations: Initialize Project, Update Hardware Schedule, Task Pinning Tool, Set Task Location Tiers. Ontario gets back related tasks by opening, and a back-to-home button sits by the project name. ([#1418](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1418), [#1601](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1601), [#1419](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1419))
- **A preview before set up.** Ontario set up shows what it will add before any write, so a project that already has doors holds no surprises. ([#1461](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1461))
- **Failed runs say why.** A run whose openings were all refused stops with the reasons instead of going green, and two failed initialize project runs were traced and fixed. ([#1545](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1545), [#1555](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1555))
- **Faster opening.** The launch copy stays on disk across relaunches, and a plan's pins arrive with the plan. ([#1339](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1339), [#1364](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1364))
- **Tag the related tasks of a list.** Select by list can pick the tasks related to a pasted list of doors, so any selection action applies to them. ([#655](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/655))
- **Upkeep.** CI drops steps that did nothing, settings meet the org standard, and an unfinished install now fails. ([#961](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/961), [#962](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/962))
