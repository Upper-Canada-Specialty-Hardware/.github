#### fieldwire_client_ucsh
32 done · 264 points · 28 pull requests merged (roney4719)

The desktop app went out in 22 releases this week, v3.0.218 to v3.0.239.

- **Set up runs on the server.** Set up now runs on the access service like updates, so it keeps going with the app closed, resumes after a redeploy and can be retried, with attributes last so doors and checklists are usable early. It re-checks at 5 and 30 minutes only. ([#1078](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1078), [#1098](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1098))
- **Automatic door pinning for the dev role.** A door model trained on the company's own plans finds each sheet's doors and pins the sure ones, sending the rest to a confirm list. Everyone else keeps today's pin review. ([#1034](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1034))
- **Screens stay as you left them.** The last six screens stay open, so coming back keeps the open door, a typed note, zoom, scroll and filters, and the title bar shows a clickable path back. Pop-outs open from what the main window already loaded. ([#893](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/893))
- **Pop-outs beside the main window.** Windows now shrink enough to sit side by side, and every row and card has a pop-out button. A door opens as a full page with a back button, and export, PDF report and mirrors are toolbar buttons. ([#879](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/879), [#922](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/922))
- **History calendar.** History gained a calendar view beside its list, so PMs and QA/QC can see how a project moved. An opening register, a plans list, a timeline and a dashboard came with it and were taken out again within the week. ([#934](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/934))
- **Fewer views.** A project now has one doors view, history keeps its list and calendar, and plans is back to its card grid, marking plans that have pins. A door's plan opens beside the door. ([#994](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/994))
- **Bigger ways back.** The faint links back, which non-technical staff missed, are now one big labelled button, the new badge on pinned projects is gone, and content moves in instead of snapping. ([#1022](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1022))
- **Deficiencies panel removed.** Everything added to show deficiencies on Ontario doors came out, since it only renamed things and nobody asked for it; related tasks stays. ([#1021](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1021))
- **Mirror projects for contractors.** Contractors can be given a mirror instead of the real project: a copy kept in sync one way, with a chooser for what it copies. ([#738](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/738))
- **Changes credited to the person.** Records made through the app now show the signed-in person in Fieldwire instead of the shared UCSH API account, and updates are credited to whoever started them. ([#751](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/751))
- **Less reliance on the shared login.** Locations and categories made in the app now show who made them. Writes Fieldwire credits to no one, such as deletes, still need the shared login, so the app adds it to a project before its first write. ([#909](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/909))
- **Sign in inside the app.** Signing in now happens in the app window with an emailed code, for ucsh.com addresses only, and every sign-in, renewal and sign-out shows in the service log. ([#798](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/798), [#580](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/580))
- **Ready for Fieldwire's December 1 cut-off.** The app moved off the API version Fieldwire is retiring to its newest, 2026-10-06, and tests now fail any write Fieldwire's published schemas don't document. ([#987](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/987))
- **Ontario takes .mdb schedules.** Ontario set up and update now take an Avaware .mdb as well as its XML export, and read both the same. ([#986](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/986))
- **Duplicate lines caught before apply.** The review page now lists duplicate checklist lines before apply, instead of an update stopping partway on them, and a duplicate door found mid-run pauses and asks. A "not a door" answer no longer fails with a database error. ([#732](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/732), [#937](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/937))
- **BC updates change door attributes.** BC updates now take the openings file next to the APM file, so changed door fields are edited in place, and a door that only lost its hardware rows is no longer marked deleted. ([#766](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/766))
- **Updates stay green.** An update could read needs attention about 3 hours after going green, because its schedule files were deleted before its re-checks. Files now stay until every re-check is done. ([#1081](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1081))

([#1091](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1091), [#1100](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1100))

Opening plans no longer blanks the window, and a failing screen shows an error page instead. ([#1009](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1009), [#981](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/981), [#975](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/975))
