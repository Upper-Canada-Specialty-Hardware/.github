#### fieldwire_client_ucsh
39 done · 312 points · 41 pull requests merged (Xilous, roney4719) · 20 releases, v3.0.285 to v3.0.304

- **Jobs run as fast as Fieldwire allows.** Long jobs now pace themselves from Fieldwire's own remaining counts instead of a fixed budget, send a door's new checklist lines in one request, and leave room for people working in the app. Before this, a mirror of a 680-door project took about 2 h 40 min where about 1 h was possible. ([#1381](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1381))
- **Project settings covers the whole project setup.** Settings is now a dashboard of the project: its information, door fields, checklists, locations, report templates, color and logo are all managed in the app, with drag and drop to reorder. Until now most of this needed Fieldwire's web app. ([#531](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/531))
- **Region switch shows the right projects.** Switching between Ontario and British Columbia now reads every project list again from the new account, so BC no longer shows Ontario's projects, and a list served by the wrong account is dropped. Anyone may now pick either region, and the region decides whose projects and which automations show. ([#1406](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1406), [#1525](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1525))
- **BC sums repeated hardware lines.** BC set up and update now add identical hardware lines on a door into one line with the quantities summed, as Ontario already did, instead of keeping the first and losing the rest of the quantity. The door's hardware table now has shortcode, hardware category, model and finish columns. ([#1437](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1437))
- **Door page on one screen.** A door's details, plan, checklist, related tasks, photos and comments now sit on one screen in three zones at a normal window width. Fields are edited in place by double-click, the checklist shows its full text and who created each line, and a mini map of the door's pin opens the plan right on it. ([#1486](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1486))
- **Sign-in with an emailed code.** People now sign in with their company email and a 6-digit code, if they are a Fieldwire user in the Ontario or BC account. Clerk, the outside sign-in service, is gone, and developer options sit in a hidden menu. ([#1530](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1530))
- **Activity panel rebuilt.** Activity is now a top bar button opening a near-full panel of every run on the account, with each step, time left and the full log. A waiting run says why and when it tries again, a quiet one says it may be stuck, and a message appears when your own run ends. ([#1610](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1610))
- **Writes follow each person's Fieldwire role.** Writes now follow the person's own Fieldwire role, nobody is made a project admin by the app, and the UCSH API account joins a project only when Fieldwire refuses a write. The larger effort to stop everyone working as one shared Fieldwire session closed with all 19 pieces done. ([#768](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/768), [#438](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/438))
- **Door finder moved, rooms name doors.** The door model behind automatic pinning moved to a new workspace and answers at 640 px, and pin review now names a door with no number after the room it opens into. Scoring the model on architects it never saw carries on in the door run work. ([#1156](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1156))
- **Updates without the old uninstaller.** Restart to update no longer runs the setup wizard or the old uninstaller, which froze twice at about 40% on 13 Nov. Closing the app installs a waiting update, the version shows in the account menu, and a developer can push a version to everyone. ([#1356](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1356))
- **UCA electrified openings in Titan.** UCA, the Ontario electrified division, can now run Titan initialize project and update on its own Ontario projects, as its own copy of the BC path. Openings get Electrified Opening tasks with every hardware line as a checklist item, openings flagged for ADO get a related ADO task, and openings with no electrified hardware are refused and reported. ([#1412](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1412))
- **License notices shipped.** The installer now carries the license texts of every open-source part it bundles, opened from an Open-source licenses item in the account menu. The backend also drops a video library the app never uses, going from 150.6 MB to 138.2 MB. ([#1128](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1128))
- **Updates download only what changed.** An update now replaces only the files that changed since the person's version, with the full installer kept as the fallback, and restart to update always installs the newest release. ([#1464](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1464))
- **Door start and end dates.** A door's start and end dates now show on the door page, edited in place or set in bulk for any selection, and are written the way Fieldwire's own app writes them, so its Gantt, calendar and overdue filter read them. ([#1614](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1614))
- **Project time zones.** Project settings now shows each project's own Fieldwire time zone instead of a blank, and door dates and activity history follow it rather than a Toronto or Vancouver default. New projects take the template's zone, else the account's. ([#1637](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1637))
- **Set up writes less.** Ontario and BC set up no longer create and write three room fields on every door that nothing reads. On one 680-door project they were 2,040 of 7,746 attribute writes, 26%, all on Fieldwire's most limited endpoint. ([#1109](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1109))
- **Mirror options switchable any time.** Every mirror option can now be turned on or off on a running mirror: turning one off stops syncing it and deletes nothing, and turning one on copies it in full on the next pass. Mirrors now copy form templates too. ([#1357](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1357))

([#1418](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1418))

([#1461](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1461))

([#1513](https://github.com/Upper-Canada-Specialty-Hardware/fieldwire_client_ucsh/issues/1513))
